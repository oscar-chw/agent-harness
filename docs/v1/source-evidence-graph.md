# v1 source-to-capability graph: retrieval and presentation slice

25 October 2026. This versioned map is **research evidence**, not installed
functionality or a v1 qualification. An edge means “worth testing,” never
“proved better.” The execution work graph, source/evidence graph, and any
derived retrieval index have different authority: a retrieval hit cannot
complete a task, grant permission, or undo a withdrawal.
