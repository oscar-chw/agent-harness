## Safety and learning

`harness privileges` reports the instruction policy. `--mode deny|ask|adaptive|scoped`
changes it with backups. Adaptive is selected locally: judge effects, target,
blast radius, reversibility, data sensitivity and current conditions. Authorized
low-risk work proceeds; unsafe unapproved effects or material uncertainty need
approval. A valid existing grant is reused within its scope. Native permissions,
organization rules and genuine guard refusals remain separate.

Learn contextual lessons from verified outcomes and explicit corrections, keeping
counterexamples and provenance. A successful command is not a safety label;
memory cannot grant approval. No trained safety classifier or measured safety
improvement is claimed. Gate fail-to-pass observations are candidates, not
automatically promoted skills. Independent promotion/effectiveness checks remain
open.

## Find current work without loading every conversation

From this project, use `harness handoff --task v2-completion --list`, then
`harness handoff --task v2-completion --packet orchestrator.md`. Read a relevant
worker packet when needed. These are bounded, advisory project files. Recheck
the original graph gate before claiming completion or taking a consequential
action. Messages activate new work or address urgent intervention; they are not
