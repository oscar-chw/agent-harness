## D: what the source proposes

**Router.** Lever maps a plain-language request to a named skill; the router resolves settings while the selected skill supplies its procedure. It distinguishes advisory work from explicit requests for actions that change external state. This is documented routing behavior, not proof that a model follows it. [Router][router], [README][readme].

**Find-loop.** For measurable iterative work, the skill first identifies an existing instrument, establishes baseline and unchanged-run variation, freezes the acceptance rule and bounds attempts. It records unsuccessful attempts and separates proposing from judging. It excludes small mechanical edits already settled by ordinary checks. Its stated project outcomes are author reports; they were not reproduced here. [Find-the-loop][find], [Loop Card][card].

**Autonomy.** Requested authority is constrained by repository and platform limits. Children may narrow it; imported text cannot raise it. Grants retain their source, scope and expiry. These are prompt-level procedures requiring actual enforcement and current evidence, not a host isolation boundary. Neither an autonomy number nor a successful experiment authorizes release here. [Autonomy skill][autonomy-skill], [autonomy specification][autonomy].

## Adaptation and non-adoption

Use the optional contract for actual bounded optimization: freeze cases/checks/scope and acceptance before observing results, bind both arms to the same context, retain each consumed attempt and count overhead. Unknown checks or usage must prevent acceptance. Never compensate for a failed case with gains elsewhere. Stop at the frozen attempt limit; changing the contract creates a new declared comparison rather than rewriting an old failed receipt.

A passing structural assessment can recommend a candidate while leaving `promotion=NOT_GRANTED`. Record source pin, contract digest, declared measurement scope, artifact/check bindings and explicit NOT_RUN/UNKNOWN in the existing checkpoint. Learning stays draft-only. Original partial cases, failed receipts and deployment boundaries remain unchanged.

Do not import Lever's autonomy defaults, spend tiers, automatic fanout, merge workflow or scheduling. Current authorization is local integration only. No performance benefit, noise calibration, generalization, installed behavior or trusted learning is established by reading these sources or authoring this example. Root's checks must reject malformed contracts and mismatched results; useful improvement still needs an independently supported comparison.
