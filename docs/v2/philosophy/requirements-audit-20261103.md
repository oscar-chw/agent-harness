## Three counterexamples where context reverses the choice

1. Authorised, low-impact cleanup in a disposable fixture differs from an
   operation against the sole shared dataset or an unauthorised production/
   network target. Judge actual effects, reversibility and existing scope.
   Neither exit0 nor an advisory privilege mode grants permission.
2. Independent substantial branches with stable interfaces and capacity can
   justify parallel investigation. Shared unresolved writes, real dependencies
   or scarce resources can require sequencing or admission waiting. A wait
   is not failed artifact acceptance; owner death is not child-stop evidence.
3. Optimistic feedback for a reversible display preference differs from
   confirming scarce stock after an ambiguous response. The latter requires
   truthful uncertainty and authoritative intent/reconciliation; a disabled
   button or key alone cannot establish that property.

All three are hypothetical exposed development cases, NOT_RUN. JSON entries
bind inspected evidence and discriminating main-owned checks. No permanent guard
rule or trained context-sensitive classifier is added. New independent cases
and complete baseline/candidate cost are required before a transfer claim.
