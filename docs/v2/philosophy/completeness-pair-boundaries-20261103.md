# Completeness pair: frozen claim boundaries

3 November 2026. Design only; calls/grading NOT_RUN.

Before either call, root freezes original questions/criteria, eligible evidence,
model/effort/tools, output budget and both treatments. Candidate combines a
generic completeness pass with lossless overlap compaction; two calls cannot
separate their effects or establish repeatable causality.

Keep three judgments separate: cited bytes support the stated claim; the answer
retains all required useful meanings; any proposed action has current authority.
Citations/checklists cannot replace meaning or permission. Unknown is not
demonstrated evidence.

Compaction must preserve selected positions, source identities and citations;
no gap bridging, cross-source merge or lost qualification. Fewer bytes are not
measured token savings.

Disconfirm the proposed improvement if required omissions persist, unsupported
claims/scope/correction regressions appear, or candidate usage exceeds baseline.
Missing evidence/usage means UNKNOWN/unqualified.
Keep per-case floors; no averaging failures or rewriting criteria.

Report each full native-call input+output total; cached/reasoning are subsets.
That pair is not whole historical project cost: prior failures and unallocated
overhead remain UNKNOWN. No retry grant, default activation, held-out/general
efficacy, or original-gate completion follows.
