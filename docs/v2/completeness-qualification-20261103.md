# A self-check helps, but does not finish the answer

3 November 2026. Two-call visible development comparison. **Do not promote.**

Both fresh native calls received the same four questions and the same 15 pinned
source windows (32,918 bytes). The candidate added a 92-word conditional draft
check. No compaction was applied: these windows have no useful overlap. Each
reader ran one allowed `cat source-packet.json`; no outside reads were observed.
This is supplied-evidence answering, not autonomous retrieval or recovery replay.

| Observation | Baseline | Candidate |
|---|---:|---:|
| Fully satisfied original clauses, including forbidden-claim checks | 9/17 | 12/17 |
| Still partial clauses | 8 | 5 |
| Complete original cases | 0/4 | 0/4 |
| Provider-reported input + output tokens | 79,065 | 67,432 |
| Wall time | 35.601 s | 47.550 s |

The native subtotal was 14.7% lower in this one pair. This is not a demonstrated
general saving: effective-model evidence is UNKNOWN, provider context/cache
conditions were not independently matched, and historical worker/root/review
overhead remains unallocated. Cached-input and reasoning counts are subsets;
they were neither subtracted nor added twice. No repeated-trial causal estimate,
held-out efficacy or complete whole-goal usage comparison was established.

The candidate restored the historical incoming-read label, missing adoption/
evaluation join, and distinction between repetition and distinct-input episodes.
It still did not fully preserve these meanings:

- No new primary **reads**, distinct from no new fetches.
- URL inventory metadata versus ingested/searchable content.
- Missing semantic/reranker and whole-corpus graph comparisons.
- The full lawful/scoped experience and authorized activation prerequisites.
- An explicit lexical/paraphrase miss and the corresponding bounded recovery.

Root checked every original clause against the complete answers and source
evidence. No forbidden assertion was observed. Original PARTIAL outcomes and the
16-case contract are unchanged; this new comparison does not close node 4.

The next diagnosis is source sufficiency as well as answer review. Some excerpts
end at a new heading or show only downstream learning operations. A generic
self-check cannot supply unsupported missing facts. Before another model trial,
map each unresolved distinction to its authorized supporting span and test
whether the selected context actually exposes it. This is a hypothesis to
investigate, not attribution of every omission to the excerpt selection.

One checker defect was independently reproduced before reviewing answers: native
receipts use `PROVIDER_REPORTED`, not `REPORTED`. The exact label was corrected;
the old checker/failure/freeze remain. Task, oracle and actor inputs did not change.
Actual-auditor controls reject unknown usage and changed answer bindings, flag
higher candidate cost and refuse to average away a regressing clause. Ruff and
whitespace checks pass. Original evidence was not edited by these controls.
